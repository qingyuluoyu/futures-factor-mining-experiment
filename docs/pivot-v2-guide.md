## 一、先搞清楚 V2 现在是什么

一句话：**在前期高点/低点处，谁冲击失败了就打谁的反方向**。

- **前期高点/低点（参考位）**：最近确认的分型极值（左/右各 3 根确认，与 V1 同口径）。
- **做空**：价格冲击前期高点但没冲过去，且出现两种证据之一——
  1. **放量拒绝**：一根长上影线（或几根累计冲高回落）配**急速放量**——多头上攻被吸收；
  2. **缩量失败**：多K线上攻到关口附近**量能急速萎缩**——上攻没有后续，衰竭。
- **做多**：完全镜像（下影线放量拒绝 / 多K下攻缩量失败，冲击前期低点失败）。
- **假信号（灰色✕）**：信号发出后价格**突破参考位**——空被涨破=假空，多被跌破=假多。
  箭头灰显带 ✕ 如实告诉你这单已经死了；突破期间不再出该侧新信号。
- 触发只评**已收盘**的 K 线，形成中的末根不评估——箭头不会盘中闪进闪出。

跟 V1 的本质区别：V1 等右侧 3 根确认后才知道那是顶/底（信号晚）；V2 在
冲击失败的当下就进场（信号早），代价是参考位被突破时要认错（灰✕）。

## 二、参数逐个讲

### 前期高低点（决定"关口"在哪）

#### 左侧确认根数（left，默认 3）/ 右侧确认根数（right，默认 3）

分型极值的确认口径，与 V1 相同。右确认 = 参考位出现后晚 right 根才生效。

- **调大**（如 5）：只认大级别关口，信号变少、更稳。
- **调小**：碎关口增多，信号变密。
- **建议**：3 通用；高周期可保持 3（参考位确认慢一点无妨，触发不等它）。

#### 冲击到位容差（proximityAtrMult，默认 1.0，单位 ×ATR）

窗口内极值离参考位多近算"冲击到位"。

- **调大**（1.5~2.0）：距关口稍远的失败也算，信号变多。
- **调小**（0.3~0.5）：只认贴着关口的拒绝，信号变少但更标准。
- **建议**：1.0 起步，嫌信号少先动这个。

### 拒绝形态（决定"什么样的失败算失败"）

#### 上攻失败深度（wickAtrMult，默认 0.8，单位 ×ATR）

失败深度 = 窗口最高价 − 收盘价。单K长上影线和多K累计冲高回落共用这个口径，
不必区分形态。

- **调大**（1.2~1.5）：只认惨烈的拒绝，信号少而重。
- **调小**（0.3~0.5）：轻微回落也算，信号变密、噪声变多。
- **建议**：0.8 起步。

#### 多K上攻窗口（attackWindow，默认 3 根）

统计失败深度的回看窗口。窗口=1 就是纯单K上影线；窗口越大，"多K缓慢爬升
后崩掉"的形态越容易被捕捉。

- **调大**（4~5）：容纳更长的上攻过程。
- **调小**（1）：只看单K影线。
- **建议**：3。

#### 同侧信号间隔（cooldown，默认 5 根）

同一侧两次信号的最小间隔，防一个关口连续刷屏。AI 策略也用它当**新鲜度窗口**
（信号超出 cooldown 根未处理视为过期）。

- **调大**：同侧信号更稀疏。
- **调小/0**：允许连续触发。
- **建议**：5。

### 量能确认（核心证据，二选一满足）

#### 急速放大下限（volExpandRatio，默认 1.5，×均量）

触发 bar 成交量 ≥ 均量×下限 → **放量拒绝**（箭头文案「空放/多放」）。

#### 急速萎缩上限（volShrinkRatio，默认 0.7，×均量）

触发 bar 成交量 ≤ 均量×上限 → **缩量失败**（箭头文案「空缩/多缩」）。

两条阈值**之间是常态量，不触发**——这是有意的：既不极端放量也不极端缩量
的冲击，说明多空都没使全力，不算证据。

- **放大下限调小**（1.2）：中等放量也算吸收。
- **萎缩上限调大**（0.8）：量能只要不太大就算衰竭。
- 两者中间带越窄，信号越少。
- **注意**：各数据源成交量口径不同（tickdata 与新浪就有差异），**换品种/
  换周期后先看信号密度再微调**，不要照抄参数。
- 量能数据缺失时自动降级为纯形态触发（沿用"数据缺失不误杀"惯例）。

#### 均量窗口（volMaPeriod，默认 20） / ATR 周期（atrPeriod，默认 14）

一般不动。

### 假信号标记

#### 假信号标记（markInvalidated，默认开）

参考位被突破的信号灰显带 ✕。只打标不过滤。

#### 隐藏假信号箭头（hideInvalidated，默认关）

开了就只看不死的信号，图面干净；默认灰显让图诚实。

#### 突破缓冲（invalidateAtrMult，默认 0 = 严格突破）

判"假"允许的插针豁免（×ATR）。0 与止损被打穿口径一致——影线穿过参考位，
挂在另一侧的止损已经成交，浅突破也是真突破。

## 三、按周期的推荐起点

量价形态对周期不敏感（ATR 和均量都自适应），同一套默认值可直接跨周期用：

| 参数 | 全周期起点 |
|---|---|
| 左/右确认 | 3 / 3 |
| 容差 ×ATR | 1.0 |
| 失败深度 ×ATR | 0.8 |
| 上攻窗口 | 3 |
| 放量下限 / 萎缩上限 | 1.5 / 0.7 |
| 信号间隔 | 5 |

嫌信号少按顺序动：容差 ↑ → 失败深度 ↓ → 量能阈值放宽。
嫌信号多：失败深度 ↑ → 容差 ↓。

## 四、常见诉求怎么调

| 你想要 | 调什么 |
|---|---|
| 信号太少 | 先升**容差**到 1.5~2.0，再降**失败深度**到 0.5，最后放宽量能两条阈值 |
| 信号太多/太碎 | 升**失败深度**到 1.2~1.5；升**左/右确认**到 4~5（关口更大） |
| 只想看贴着关口的拒绝 | 降**容差**到 0.3~0.5 |
| 只信放量吸收、不信缩量衰竭 | 萎缩上限设 0（只留放量分支） |
| 只信缩量衰竭 | 放大下限设一个很大值如 99（只留缩量分支） |
| 同一关口反复出信号烦 | 升**信号间隔** |
| 假信号 ✕ 太多 | 这是参考位被突破的如实呈现：先检查关口参数（左右确认调大让关口更硬）；插针误伤再调**突破缓冲**到 0.2~0.3 |
| 想眼不见为净 | 开**隐藏假信号箭头** |
| 参数调乱了想回起点 | V2 设置面板底部「**恢复默认参数**」 |
| 想沿用我调好的 V1 关口口径 | 面板底部「**参数对齐 V1**」（对齐左右确认与箭头颜色） |
| 想回到旧版 V2（分型+趋势门） | 用 V1（旧 V2 已被本版替换，历史见 Git） |

## 五、还没有做的验证

- 本版的默认值经过 6 品种 × 4 周期的**触发量校准**（防退化：不出现 0 信号或
  爆量，数字见 PR 描述），但**盈亏层面的回测验证还没做**——「量价拒绝在
  期货上是否赚钱」需要用回测跑 `swing_pivot_v2` vs `swing_pivot`，量命中率
  与盈亏比，目前没做。
- 量能口径差异（tickdata vs 新浪）对阈值的影响未系统量化，换数据源后建议
  重新目检信号密度。
