**状态：已实现待验证。** 本文只覆盖股票只读模型历史API工作包。离线ASGI及真实原生模型登记夹具通过，不代表原PG、生产HTTP、本人页面或完整ML产品验收。本包没有启动任何原服务、迁移、任务或外部模型调用。

原有认证/期货/共享配置、015–018、数据库和旧API没有在本包修改。019模型登记由并行独立包实现；本包复用其 `ModelRegistryService` 和 `ModelPage/ModelDetail/ModelReport`，没有新建计算核、产物存储或训练执行器。本包没有修改 `stock_factors.py`；正式股票路由挂载由根执行单独兼容验证。

`require_stock_market` → 现有 `AuthContext`（JWT本人及盘）→ `Scope(owner_id,trading_mode)` → 同一 `get_session` → `ArchiveService` → `ModelRegistryService` → Pydantic输出复核。产物仅来自既有 `request.app.state.stock_research_artifact_store`，必须是 `ArtifactStore` 实例；不接受客户端owner/盘/model_path，不从请求构建存储目录。

|GET路径（股票router下）|契约|
|---|---|
|`/research/v2/models/availability`|`{listing_enabled:bool,training_enabled:false,reason:str}`；默认关闭或缺存储时200明确不可用，不探测019、不加载原生ML|
|`/research/v2/models`|`limit=20`，范围1–100；`offset=0`，范围0–100000；返回`ModelPage`，分页总数和`has_more`由服务给出|
|`/research/v2/models/{UUID}`|`ModelDetail`，包含固定参数、1–5个fold、数据/特征版本、QA状态和限制|
|`/research/v2/models/{UUID}/report`|`{kind:'stock-walk-forward-calculation-v1',report:dict}`；服务验证登记/范围/内容指纹，不重新评估最终测试|

四条路径均要求A股会话。开关 `app.state.stock_ml_registry_enabled is True` 才可读取，`1`/字符串不开放。关闭时除availability外返回503 `ml_registry_disabled`；缺存储503 `artifact_store_unavailable`；缺019/015保持服务明确503。所有GET禁止未知query字段。非法页码/UUID422、未登录401、冻结403、期货会话409、异用户/异JWT盘404。没有POST、注册、训练、评价、写审计或任务启动入口。

每次GET返回 `X-Request-ID`、`Cache-Control: private, no-store`、`X-Content-Type-Options: nosniff`，错误体与请求号一致。接口8秒超时504，结构不符/内部异常503；错误体不回显异常内容、输入、路径或密钥。日志记录请求号、用户、盘、operation、耗时及`writes=0 model_calls=0`。服务 `JobError` 保留原码，不把失败变为空列表；019的报告8MiB交互上限超限码同样透传，不新增伪导出入口。

金融公式、标签、费用、成交口径没有变化。历史仍为 `qa_only/research_only`，`holdout_registry_verified=false`；分数不是收益概率、重要性不是因果，未取得来源/经济标签/最终测试资格。
