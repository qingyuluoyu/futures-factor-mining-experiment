## 3. 本轮改良的具体数据流

### A股研究

参数编辑/恢复 → 既有类型契约 → 本地行情/估值/公告面板 → 金融域资格掩码 → 去极值/按配置填充 → **可识别性门** → 中性化/标准化 → 原IC/组合内核 → 保存版本/政策 → 报告原样读取。

方法升级`stock-research-2026-10-19.v5`；旧结果不改。行业单样本保持缺失；联合设计矩阵不满列秩或样本数≤秩时不产生残差。报告解析校验政策，显示不足保持缺失，不把v5政策追填旧报告。此修复不是基准、PIT、可交易回放或五年性能完成。

### 期货资产

真实JWT用户/盘 → 原账面摘要（旧契约保留） → 账户+本人该账户正持仓单次join读取，强制刷新ORM已有实体 → 一次同盘Redis MGET → 来源/合约/价格/接收时间校验 → Decimal多空×数量×存储乘数 → 新增typed `valuation` → 工作台/资产/模拟资金面板。

最多1000持仓/2秒缓存读取预算；无live/legacy补价或供应商外呼。任何持仓不可估值则整个浮动估值不可用，不返回部分权益。recv_ts是缓存接收时间，不是交易所成交时间；来源白名单不是独立来源认证。收盘缓存超过120秒会显示账面权益/未知浮盈，不能当后台错误自动补造价格。

`book_equity=balance+frozen`，参考权益加浮盈；负权益保留，非正权益风险率null。空持仓可确定浮盈0；今日盈亏没有交易日基准始终null。保留top-level旧账面total_equity和两个旧0字段，新增`equity_basis`、`legacy_pnl_fields_available=false`避免破坏AI任务旧现金基线；**旧客户端若忽略标志仍有误读风险**，需后续版本化迁移，不宣称所有消费方已统一。
