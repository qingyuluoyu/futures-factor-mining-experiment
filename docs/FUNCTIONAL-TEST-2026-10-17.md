## 必须阻断验收的问题

### 1. 双市场隔离失败

- 浏览器复现：期货选择 `rb2701` → 切 A 股仍以 `rb2701` 请求股票数据 → 选择 `000001` → 切回期货仍显示 `000001`，期货盘口为空。
- A 股模式进入“交易”，标的是 `000001`，但界面仍为“买多 / 卖空 / 数量（手）/ 可用保证金”，并展示 `rb2701` 的期货模拟订单。不能把此页面算作已实现 A 股模拟交易。
- `StockMarketView` 读写期货全局 `activeContract`，相关菜单和入口没有完整分流。
- `/api/factor-mining/symbols` 实测混入 300 个股票代码；期货历史查询相关函数缺少市场过滤。
- 自选排序仅按用户匹配：virtual 请求可把同一用户 live 自选的排序由 0 改为 123。跨用户拒绝虽然通过，跨盘边界仍失败。
- 自选非法市场输入在不重复标的上返回 201；先前同标的测试的 409 实际来自重复保护，不是市场参数校验。

### 2. A 股金融计算不正确

- 零费用、固定持有最高动量股票的确定性数列中，末值应约为 **1.136408**，程序返回 **1.1394**。现实现把整段收益平均摊成每日收益后复利，扭曲净值、波动和回撤。
- 因子检验把未来 `horizon` 日多空收益除以 `horizon` 当作每日实现收益。未来收益可作为 IC 标签，但不能这样构造可执行多空净值。
- 缺少已持有股票价格时，净值会出现 NaN，实际接口序列化为 null；未提供可解释的停牌估值或明确失败处理。
- 选中 `ret_20d + roe`，当 ROE 全无数据时会静默退化为仅动量，返回参数仍声称使用两个因子。
- 先行业去均值、再市值回归并不能同时中性化；独立样本的两个行业残差均值为约 **+0.428571 / -0.428571**。
- 市值矩阵与选股列未完整对齐，市值权重实际发生 KeyError / HTTP 500。
- 未知检验因子返回 500；非法调仓频率与权重输入被接受为 200。需要契约校验，不能靠默认分支悄悄替代。

以上确定性数列只用于单元测试，不是伪造业务行情或替代真实链路。业务数据验证没有使用 mock 报价冒充供应商数据。

### 3. 题目二仍有未接通链路

代码审阅确认，现有股票 API 仅有固定因子目录、即时分析和即时回测，没有股票自定义因子、可恢复异步研究任务、研究结果持久化及历史报告完整接口；现有股票研究页也没有完整预处理和区间配置入口。当前数据库重复计算一致，不等于有不可变输入数据版本和历史报告。

历史成分、退市样本、财报修订版本、复权增量一致性、涨跌停及流动性约束、税费和交易时点尚未通过完整验收。不得使用当前输出作为可靠策略或实盘依据。
