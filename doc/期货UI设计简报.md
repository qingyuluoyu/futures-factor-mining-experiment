# 期货交易系统 UI 设计简报

## 1. 功能概述

面向量化/半量化交易员的专业期货交易 Web 系统，包含 10 个交易客户端页面和 9 个管理后台页面。设计目标是打造高信息密度的暗色交易终端，让用户在单屏内获取尽可能多的市场数据并快速执行交易决策。后端仅实现登录/注册/JWT 鉴权/用户信息管理，管理后台仅做前端静态 UI。

## 2. 核心用户行为

**看数据 → 做决策 → 执行交易**。量化用户的核心需求是快速扫描多品种行情、快速下单、实时监控持仓风险。每一秒的延迟和每一次多余的点击都是成本。

## 3. 设计方向

**专业交易终端风格，深色暖灰调性。**

- **色彩基调**：深暖灰背景（#1a1a1e ~ #2a2a2e），长时间盯盘眼睛舒适
- **数据高亮**：红涨绿跌（中国惯例），重要数字用亮色（青色 #00d4aa、琥珀色 #f5a623）
- **信息密度**：紧凑排列，小字号（12-13px 正文），数字等宽对齐，单屏最大化数据展示
- **视觉参考**：文华财经、Bloomberg Terminal 的信息密度 + TradingView 的现代交互感
- **整体感受**：冷静、精确、高效、专业

## 4. 布局策略

### 全局框架（所有用户端页面共享）

```
+----------------------------------------------------------+
| 顶部导航栏 (h-14, 固定)                                    |
| Logo | 市场状态灯 | 连接状态 | 快速搜索 | 通知 | 用户菜单    |
+--------+-------------------------------------------------+
| 左侧    | 主内容区 (calc(100vh - 56px))                     |
| 菜单    |                                                  |
| (w-48,  | 面包屑 + 页面专属内容                              |
| 可折叠  |                                                  |
| 至图标) |                                                  |
+--------+-------------------------------------------------+
```

- 顶部导航栏 56px 固定，左侧菜单 192px 可折叠至 48px 图标模式
- 主内容区 `calc(100vh - 56px)` 不允许页面级滚动（交易页面），仅局部区域可滚动
- 1440×900 适配：菜单默认折叠为图标模式，次要面板可折叠

### 页面级布局策略

| 页面 | 布局策略 |
|------|----------|
| 登录/注册 | 全屏居中卡片，背景渐变动画 |
| 工作台 Dashboard | 栅格卡片（4列），上方资产条横贯全宽 |
| 行情中心 | 三栏（合约列表 \| K线+盘口 \| 下单面板），比例 2:5:3 |
| 交易面板 | 经典三栏（合约选择 \| 下单卡片 \| 委托/持仓） |
| 持仓管理 | 全宽表格，顶部筛选栏，底部汇总行 |
| 订单管理 | Tab 切换 + 全宽表格 |
| 资产中心 | 上方卡片组 + 下方 Tab 内容 |
| 历史数据 | 上方筛选条件 + 图表区 + 表格区 |
| 个人中心 | 左右分栏（设置菜单 \| 内容区） |
| 消息中心 | 时间轴列表 + 筛选栏 |
| 管理后台 | 统一三栏框架（管理菜单 \| 主内容），菜单更宽更丰富 |

## 5. 关键状态

| 状态 | 说明 | 处理方式 |
|------|------|----------|
| 未登录 | 访问任何页面 | 重定向至登录页 |
| 空数据 | 新用户无持仓/订单 | 显示空状态插图 + 引导文案 |
| 加载中 | 行情/订单数据加载 | 骨架屏（Skeleton），不使用 Spinner |
| 实时更新 | 行情数据推送 | 数字闪烁动效（变色后渐退），不重新渲染整个区域 |
| 网络断开 | WebSocket 断开 | 顶部导航栏状态灯变红 + Toast 提示 |
| 下单确认 | 提交订单前 | 弹窗二次确认，显示合约、方向、价格、数量 |
| 风控预警 | 风险率 > 80% | 持仓行红色边框闪烁 + 消息中心推送 |
| 错误 | 操作失败 | Toast 红色提示，包含错误原因 |
| 交易时段外 | 非交易时间 | 市场状态灯灰色，下单按钮禁用 + 提示文案 |

## 6. 交互模型

### 全局交互
- 左侧菜单：hover 展开子菜单，当前页高亮，点击切换页面
- 顶部导航：市场状态灯（绿=交易中、黄=休市、红=断线）、快速合约搜索（支持代码模糊匹配）
- 键盘快捷键：ESC 关闭弹窗、Enter 确认、数字键快速切页

### 行情中心交互
- 左侧合约列表：点击切换 K 线，星标收藏，搜索过滤
- K 线图：拖拽平移、滚轮缩放、双击复位、工具栏切换周期/指标
- 盘口：五档买卖挂单实时更新，价格 hover 高亮对应档位
- 双击合约行 → 跳转交易面板并带入合约信息

### 交易面板交互
- 买卖方向按钮：大号醒目，红色买多/绿色卖空/灰色平仓，切换时表单重置
- 价格输入：支持键盘输入 + 点击盘口价格自动填入
- 下单按钮：二次确认弹窗，3 秒无操作自动消失取消
- 委托列表：实时刷新，支持单笔撤单 + 一键全撤

### 持仓/订单交互
- 表格行：hover 高亮，点击展开详情
- 操作按钮：平仓 → 确认弹窗，止盈止损 → 小弹窗设置
- 排序：点击表头切换升序/降序

## 7. 内容需求

### 数字格式化规则
- 价格：保留合约最小变动位（如螺纹钢 1 位，股指 0.2 位）
- 百分比：统一 2 位小数，带 % 号
- 盈亏：正数红色加 `+` 前缀，负数绿色加 `-` 前缀
- 金额：千分位逗号分隔
- 数量：整数，手为单位

### 全局文案
- 上涨颜色：`#ef4444`（红），下跌颜色：`#22c55e`（绿），平盘颜色：`#9ca3af`（灰）
- 空状态："暂无持仓数据"、"暂无委托记录"
- 确认弹窗："确认提交限价单？合约 XXX 方向 买 价格 XXXX 数量 X 手"
- Toast 成功："委托已提交"、"撤单成功"
- Toast 错误："网络异常，请重试"、"可用保证金不足"

### 管理后台文案
- 管理端页面标题带 "管理" 前缀区分：用户管理、合约管理、风控监控等
- 状态标签：正常（绿）、冻结（红）、审核中（黄）

## 8. 字体方案

- **UI 字体**：系统默认字体栈（-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif）
- **数字字体**：JetBrains Mono（等宽），用于价格、数量、盈亏等数字区域，确保对齐
- **正文字号**：12-13px，标题 16-18px，数据标签 11px

## 9. 快捷键体系

第一期即实现完整快捷键系统：
- ESC：关闭弹窗/取消操作
- Enter：确认当前操作
- 1-9：快速切换左侧菜单页面
- F1-F4：切换 K 线周期（分时/分钟/小时/日线）
- Ctrl+K：打开快速合约搜索
- Ctrl+B：买多下单
- Ctrl+S：卖空下单
- Ctrl+D：一键全撤委托

## 10. 多标签页状态同步

支持浏览器多标签页同时使用：
- 通过 BroadcastChannel API 实现标签页间通信
- 同步状态：持仓变更、订单状态、资产变化
- 行情数据共享：避免每个标签页都建立独立 WebSocket 连接

## 11. 技术实现参考

| 领域 | 方案 |
|------|------|
| UI 组件库 | shadcn/ui（Tailwind 原生，高度可定制） |
| 布局框架 | 全局 Shell（Nav + Sidebar + Content）封装为 Layout 组件 |
| 数据表格 | shadcn/ui DataTable（基于 TanStack Table），支持虚拟滚动 |
| K 线图表 | lightweight-charts，封装为独立组件，支持多周期切换 |
| 实时数据 | 前端 WebSocket 管理器 + React Context 全局状态 |
| 表单处理 | shadcn/ui Form（基于 React Hook Form + Zod 验证） |
| 数字动画 | 数字变化时 CSS transition 或 countup.js 效果 |
| 暗色主题 | Tailwind CSS dark mode + CSS 变量定义色板 |

## 13. 页面实施优先级

1. **P0 - 全局框架**：Layout Shell（导航 + 侧边栏 + 内容区）+ 色板 + 暗色主题
2. **P1 - 核心交易流**：登录/注册 → 工作台 → 行情中心 → 交易面板
3. **P2 - 仓位管理**：持仓管理 → 订单管理 → 资产中心
4. **P3 - 辅助功能**：历史数据 → 消息中心 → 个人中心
5. **P4 - 管理后台**：9 个管理页面（前端静态 UI）
