| 层 | 技术 | 用途 |
|----|------|------|
| **Web框架** | FastAPI | REST API + WebSocket 全支持，自动生成文档 |
| **实时行情** | AKShare + Redis Pub/Sub | AKShare 定时拉取数据，push 到 Redis，FastAPI 订阅并广播 WebSocket |
| **任务调度** | APScheduler 或 Celery | 定时获取数据、生成K线、收盘结算 |
| **ORM** | SQLAlchemy (asyncio) 或 Tortoise-ORM | 操作 PostgreSQL |
| **数据库** | PostgreSQL + Redis | PG 存用户、订单、持仓、K线；Redis 缓存行情、会话、挂单 |
| **K线数据** | TimescaleDB (PG 扩展) 或直接 PG | 存储历史K线 |
| **前端** | React + TypeScript + lightweight-charts | 图表与交易界面 |
| **部署** | Docker + Uvicorn workers (多核启动) | 利用多进程提高并发能力 |
