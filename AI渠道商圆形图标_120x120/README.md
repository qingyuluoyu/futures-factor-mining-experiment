# AI 渠道商圆形图标（120×120）

- 共 53 枚：美国 23 枚，中国 30 枚。
- 格式：PNG / RGBA，画布 120×120 px，透明四角，圆形白底，品牌标识居中。
- 分组目录：`美国/`、`中国/`。
- 预览：`美国_预览.png`、`中国_预览.png`。
- 明细：`图标清单.csv`。

## 口径说明

“所有”没有封闭边界（仅中国已备案的大模型就有数百个），本套按中美主流通用大模型、AI 助手、模型平台、聚合/推理渠道整理，重点覆盖 GPT、Claude、Gemini、DeepSeek、Qwen、豆包、Kimi 等常用品牌。

## 图标来源与使用

品牌图形取自 Lobe Icons 的静态 PNG 资源（MIT License）：https://github.com/lobehub/lobe-icons
OpenAI 等品牌标识仍受各自商标与品牌规范约束；请在公开或商业场景中遵守对应品牌方的使用规则。
